# Visual References

These images are reference material for the recreation benchmark.

## Files

- `campus_zoning_reference.jpg` — campus extent and functional-area annotation.
- `campus_aerial_reference.jpg` — aerial top-down view for footprint and overall-layout verification.

## Interpretation

The zoning image indicates:

- red: campus boundary;
- pink: dormitory range;
- blue: teaching / classroom range;
- orange: cafeteria range.

The raw aerial image should be used to verify building footprints, roads, plazas, sports areas, and the overall campus layout.

These images do not replace the source SKP for 3D height, bridge, platform, slope, or terrain relationships.
