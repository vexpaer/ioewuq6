# Campus reconstruction

Primary deliverable: `campus_recreated.blend`.

The model was rebuilt in Blender 5.2.0 from a factory-empty scene using
procedural semantic mesh construction. The locked SketchUp file and supplied
reference images were used for inspection and measured layout anchors only;
the submission contains no imported source geometry or linked libraries.

The file is organized into `Terrain`, `Roads`, `Platforms`, `Bridges`,
`Buildings`, `Sports`, `Stairs`, and `Details` collections. Major site
features include the terraced campus, perimeter and diagonal roads, upper and
lower teaching groups, residence/service wings, athletics track, sports
fields/courts, elevated atrium, stairs, bridges, railings, facade modules,
rooftop equipment, landscaping, and public-realm details.
